# Level 1: The Open Vault

This program is a simple vault. Anyone can create a vault they own, anyone can
deposit SOL into a vault, and only the vault's owner should be able to withdraw.

Somebody has found a way to withdraw from vaults that are not theirs.

**Your goal:** stop the exploit without breaking deposits or the owner's own
withdrawals. Edit the program, then submit. Hidden tests will attack your fix.
